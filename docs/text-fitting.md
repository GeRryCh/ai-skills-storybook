# Text Fitting & Panel Sizing

How `overlay_text.py` sizes story text and the semi-transparent panel behind it, in both
text modes that composite text with Pillow. Source of truth: the module constants and the
two fit loops in `skills/storybook-render/scripts/overlay_text.py` — this doc explains the
design; the code defines the numbers.

---

## The two modes

| | Band mode | Text-page mode |
|---|---|---|
| Used by | `overlay` mode pages, `native`/`long` covers | `long` mode body text pages |
| Function | `overlay()` + `_pick_font_size()` | `text_page()` (own fit loop) |
| CLI | default | `--text-page` |
| Background | the page's own art, untouched | a purpose-made background generated by the render stage (`pages/text-bg-long.png` or a per-page dedicated bg), used as-is — no blur, no wash |
| Panel position | flush to bottom (full-bleed edge) or top with 4% margin, per `--placement` | vertically centered |
| Panel corners | rounded; bottom placement drawn past the canvas edge so the bottom edge reads straight | all four corners rounded (panel floats) |
| Vertical padding | asymmetric 40px top / 56px bottom (balances the feather blur) | symmetric ~48px |
| Font start size | 72px (`MAX_FONT_PX`) | 96px (`TEXT_PAGE_MAX_FONT_PX`) |
| Comfortable zone | 25% of page height (`TEXT_ZONE_FRACTION`) | 60% of page height (`TEXT_PAGE_ZONE_FRACTION`) |
| Hard box cap | ⅓ of page height (`MAX_BOX_FRACTION`) | 80% of page height (`TEXT_PAGE_MAX_BOX_FRACTION`) |
| Font floor / abs min | 22px / 12px (`MIN_FONT_PX` / `ABS_MIN_FONT_PX`) | same (shared constants) |

Both panels span the full width minus a 5% margin per side (`H_PAD_FRACTION`), extended
outward by a 40px inner pad (`H_INNER_PAD`) so the text never touches the panel edge.

## The fit algorithm (same shape in both modes)

The box is **sized to the text**; the font is fitted first and the box follows. Width is
fixed, so fitting is purely vertical: wrap the text at a candidate font size, measure the
wrapped block, compare against a height limit.

1. **Phase 1 — comfortable zone, legible font.** Start at the mode's max font size and
   shrink in 2px steps until the wrapped text + padding fits the comfortable zone
   (25% band / 60% text-page), stopping at the 22px legibility floor. Most pages exit
   here; the panel ends up no taller than the zone.
2. **Phase 2 — overflow growth.** If even 22px cannot fit the zone, the panel may grow
   past it up to the hard cap (⅓ band / 80% text-page), while the font continues
   shrinking below the floor, down to the 12px absolute minimum. The cap is what keeps a
   band from swallowing the artwork, and a text page from running edge-to-edge — the
   centered 80% cap always leaves ≥10% of the page height free above and below.
3. **Last resort — clipping.** At 12px font and a cap-height panel, any remaining lines
   are clipped at the panel edge (the draw loop stops; nothing overflows outside the
   panel). In practice this needs roughly 2× the word count of a heavy long-mode page
   (the STYLE_PRIMER guidance of 80–200 words per long-mode page fits in phase 1).

Measurement uses the **actual resolved font and the actual text** (wrapped with the same
`_word_wrap` used for drawing), so the fitted size matches what is rendered. An earlier
version measured a `"X " * word_count` proxy, which under-counted lines and clipped real
text — don't reintroduce proxies into the fit loops.

## Deliberately separate code paths

`text_page()` does **not** call `overlay()` or `_pick_font_size()` — it has its own fit
loop and geometry, sharing only the small helpers (`_word_wrap`, `_resolve_font_ref`,
`_load_font`) and the feathered-panel mask recipe. This is a regression guard: tuning
long-mode text pages cannot change band-mode output, and vice versa. Keep it that way —
if the two loops drift toward a shared abstraction, the coupling reintroduces exactly the
risk the split was made to remove.

## The panel

Both modes draw the same panel: a rounded white rectangle at `--box-alpha` opacity
(default 205/255) on its own alpha mask, Gaussian-blurred by `--feather` px (default 14)
so it fades into the background instead of ending at a hard edge. Text is composited on a
separate layer and stays crisp. In text-page mode the purpose-made background already
reserves a light low-detail center, so the panel often blends in almost invisibly — it
earns its keep when long text outgrows the reserved zone and lines land on busier areas
of the background.

## Tuning

All knobs are module constants at the top of `overlay_text.py`, with the panel ones also
exposed as CLI flags (`--box-alpha`, `--feather`, `--align`). Tuning is zero-cost: re-run
`overlay_text.py` against the committed fixture pages (see "Smoke-testing changes" in
CLAUDE.md) — no API call involved.
